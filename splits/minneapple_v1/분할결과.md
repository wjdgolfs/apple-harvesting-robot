## 검사
- 시퀀스 중복: 0 / 파일명 대응: 670쌍 / 분할 간 동일 이미지 SHA-256 중복: 0
- 검증 이미지별 가장 가까운 학습 이미지 dHash 중 최소 거리: 14
- dHash는 장면 유사성의 보조 검사다. 같은 나무·배경의 누출이 없다고 보증하지 않는다.

## 생성 파일
- manifest.csv: 이미지·마스크 대응, 배정, 크기, 주석 수, 원본 해시
- train_images.txt / val_images.txt: train 데이터 루트를 기준으로 한 이미지 상대 경로
- train_masks.txt / val_masks.txt: 대응하는 원본 마스크 상대 경로
- summary.json: 배정 통계 및 검사 결과
- nearest_cross_split_pairs.json: 수동 확인용 유사 이미지 후보

## 한계
- 파일명 접두사를 촬영 시퀀스 그룹으로 사용했다. 서로 다른 그룹에 같은 나무·과수원 배경이 포함될 수 있다.
- 전경 나무의 사과만 주석하는 데이터 정책을 따른다. 화면 전체의 모든 사과 검출을 평가하는 분할은 아니다.
- 검증 자료는 학습 중 모델 선택용이다. 독립적인 최종 시험 성능으로 표현하지 않는다.
- 이미 살펴본 샘플이 일부 포함된다. 완전히 보지 않은 평가 자료라고 주장하지 않는다.
- 가중치 학습이나 예측 성능을 이용해 분할을 선택하지 않았다. 이후 검증 결과에 맞춰 분할을 변경하지 않는다.
