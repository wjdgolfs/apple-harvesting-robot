# Colab 기본 학습 실행

로컬 RTX 5060 Laptop 8GB에서 전체 데이터 학습은 batch 2와 batch 1 모두 CUDA 메모리 부족으로 중단됐다. batch 1의 첫 epoch 체크포인트는 로컬에 보존한다.

## 준비한 파일

- 실행 노트북: `colab/MinneApple_YOLOv8n_seg_baseline.ipynb`
- Colab 학습 코드: `colab/train_colab.py`
- 전송 파일 생성: `prepare_colab.py`
- 전송 ZIP: `outputs/colab_transfer/minneapple_colab_v1.zip` (약 1.25 GB)
- 전송 검수 기록: `outputs/colab_transfer/transfer_summary.json`
- Drive 폴더: https://drive.google.com/drive/folders/1QUQdYrnkwZ8HmfyzSms7-M039tuBmfHd

Drive 연결 도구의 파일당 512MB 제한 때문에 ZIP을 .001/.002/.003 세 조각으로 전송한다. 노트북에서 각 조각과 합친 ZIP의 SHA-256을 모두 검사한다. 세 조각은 파일 이름을 그대로 유지한다.

ZIP에는 학습용 이미지·YOLO 라벨·고정 분할 명세·ID 대응표·원래 COCO 사전학습 가중치·실행 코드만 포함한다. 원본 마스크와 독립 시험 이미지는 전송하지 않는다. 데이터 원본은 수정하지 않는다.

## 실행 순서와 이유

| 순서 | 할 일 | 확인하는 내용 |
| --- | --- | --- |
| 1 | Drive 폴더의 노트북을 Colab으로 열기 | 프로젝트별 실행 기록을 남긴다 |
| 2 | 런타임 → 런타임 유형 변경 → GPU | 실제 할당된 GPU와 VRAM은 첫 셀에서 확인한다 |
| 3 | 첫 셀 실행 | Ultralytics 8.4.215 설치 및 GPU 확인; 기존 Colab CUDA PyTorch는 유지한다 |
| 4 | Drive 연결 셀 실행 및 본인 승인 | 데이터 읽기와 체크포인트 저장 경로를 연결한다 |
| 5 | 복사·무결성 확인 셀 실행 | VM 디스크에 ZIP을 복사하고 SHA-256·파일 수·라벨 행 수를 검사한다 |
| 6 | 기본 학습 실행 셀 실행 | 전체 데이터 학습, 매 epoch 후 Drive 백업 |
| 7 | 결과 확인 셀 실행 | 완료 상태·완료 epoch·모델 로드·손실 유한값 여부를 확인한다 |

학습 518장/22,082개 주석, 검증 152장/6,101개 주석이다. ZIP 내 1,348개 파일의 SHA-256을 검사했다. 총 28,183개의 사과 주석이 유지된다.

학습 설정은 `imgsz=640, batch=1, mask_ratio=1, overlap_mask=True`, 최대 50 epoch, patience 10, seed 42, AdamW, 증강 없음이다. 로컬 실패 시도를 그대로 재개하지 않고 원래 사전학습 가중치에서 새로 시작한다. 데이터 분할·라벨·학습 설정은 유지하되 GPU·Python·PyTorch 등 런타임 차이는 기록한다. 메모리 부족 시 설정을 자동으로 낮추지 않는다.

## 저장과 중단 확인

- 데이터 위치: `/content/apple_baseline_bundle` (Colab 임시 VM 디스크)
- 학습 결과: `/content/runs/baseline_colab_<UTC시각>`
- 영구 백업: `MyDrive/apple-harvesting-robot-colab-20261116/outputs/baseline_colab_<UTC시각>`
- 주요 파일: `weights/best.pt`, `weights/last.pt`, `results.csv`, `results.png`, `baseline_summary.json`, `environment.txt`, `mask_preflight.csv`, `run.log`
- 매 epoch 후 `DRIVE_BACKUP` 메시지를 확인한다. 백업 오류가 표시되면 Drive 공간과 연결을 확인한다.
- 오류 시에도 현재 로그·상태와 마지막으로 저장된 체크포인트를 Drive로 복사한다. 저장 전 중단된 epoch의 진행분은 복구되지 않는다.
- 새 런타임에서 실행 셀을 다시 실행하면 별도 이름으로 새 학습을 시작한다. 중복 실행 전 기존 런타임이 살아 있는지 확인한다.

무료 Colab은 GPU 종류·사용 가능 시간·할당량을 보장하지 않는다. 공식 FAQ의 최대 실행 시간도 보장 시간이 아니다. 유료 결제는 진행하지 않는다. 실제 epoch 속도를 확인한 뒤 완료 예상 시간을 판단한다.

검증 지표는 모델 선택용이다. 독립 시험 이미지 추론은 학습 완료 후 다음 단계에서 진행한다.

## 전송 파일 다시 만들기

레포 폴더의 PowerShell에서 실행한다. 기존 ZIP이 있으면 덮어쓰지 않고 중단하므로, 새 출력 디렉터리를 지정한다.

```powershell
.\.venv-inspection\Scripts\python.exe prepare_colab.py --output outputs/colab_transfer_v2
```

새 ZIP을 생성하면 노트북의 예상 SHA-256도 새 파일에 맞춰 갱신된다. ZIP과 노트북을 함께 다시 업로드해야 한다.
