# apple-harvesting-robot
사과 수확 로봇 아자아자 화이팅

이 저장소에서는 사과 이미지의 데이터 준비, 모델 학습, 추론, 평가에 필요한 코드와 설정을 관리한다. 발표 자료, 보고서, 검수 사본은 저장소 밖에 보관한다.

11월 16일 학습 결과로 주간 수치를 다시 계산하거나 예전 발표 자료를 재생성할 때는 `MINNEAPPLE_BASELINE_RESULTS_DIR`에 보관된 `MinneApple_기본학습_20261116` 폴더의 경로를 지정한다. 이 폴더에 `results.csv`와 당시 그래프·로그가 있다.
