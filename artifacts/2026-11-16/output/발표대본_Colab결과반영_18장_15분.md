그래프는 매 학습 회차의 검증 mAP50입니다. 박스와 분할의 학습 손실은 각각 약 2.24에서 1.33, 2.99에서 1.89로 감소했지만 검증 성능은 계속 좋아지지 않았습니다. 따라서 학습을 더 오래 하는 것만으로 개선된다고 판단하지 않았습니다. 다음 장은 선택된 모델을 마지막에 다시 검증한 결과입니다.

이렇게 나눈 이유는 모델을 바꾸는 효과와 가림 증강의 효과를 구분하기 위해서입니다. 색 기준과 원본 ResNet을 비교해 전이학습의 변화를 보고, 원본 ResNet과 증강 ResNet을 비교해 가림 대응의 차이를 살펴봤습니다.

## 9 가림 증강 후 익음 누락 감소

먼저 익음도 결과입니다. 가로축은 사과에 추가한 합성 가림률이고, 세로축은 실제 익음 중에서 모델이 익음으로 찾은 비율인 재현율입니다. 평가 대상은 202개 관측 영역이며, 익음 20건과 미숙 182건으로 구성했습니다.

빨간색의 기존 색 기준 모델은 추가 가림 30퍼센트와 50퍼센트에서 익음 20건을 모두 놓쳤습니다. 파란색 ResNet 원본 학습 모델은 가림에서 판정을 더 유지했고, 초록색 증강 모델은 0퍼센트와 15퍼센트에서 19건, 30퍼센트와 50퍼센트에서 18건을 찾았습니다.

즉, 증강 모델은 추가 가림 50퍼센트에서도 익음 재현율 90퍼센트를 유지했습니다. 다만 이 결과에는 같은 과실의 여러 관측이 포함되어 있고 정답 사과 영역을 사용했습니다. 또 익음을 잘 찾는 것과 미숙을 잘못 선택하지 않는 것은 별개의 문제입니다.

## 10 원본 조건의 익음 정밀도

목표 60초 / 06:45–07:45

화면 안내: 35.2%와 혼동행렬의 19·35를 함께 가리키기

그래서 익음 정밀도와 오선택도 함께 확인했습니다. 재현율이 실제 익음을 얼마나 놓치지 않았는지를 뜻한다면, 정밀도는 익음이라고 선택한 대상 중 실제 익음의 비율입니다.

표의 원본 조건을 보시면 실제 익음 20건 중 19건을 찾았지만, 미숙 182건 중 35건도 익음으로 잘못 판단했습니다. 따라서 익음으로 선택한 대상은 총 54건이고, 그중 실제 익음은 19건입니다. 이를 나누면 정밀도는 35.2퍼센트입니다.

이는 기존 색 기준 모델의 36.2퍼센트보다 높아지지 않은 결과입니다. 가림에서 익음 누락은 줄었지만, 수확 후보를 정확히 선별하려면 오선택 감소가 더 필요합니다. 전체 정확도 하나만으로 판단하지 않고 정밀도와 재현율을 함께 제시하는 이유입니다.

## 11 무게 추정 비교 조건

목표 45초 / 07:45–08:30

화면 안내: 학습 48과실·평가 12과실과 전체 사진 입력 조건 강조

무게 추정도 세 가지 모델을 비교했습니다. 기존 방법은 이미지에서 보이는 사과 면적을 이용하는 회귀 모델입니다. 여기에 원본 이미지의 ResNet18 특징을 이용하는 회귀 모델과, 합성 가림을 함께 학습한 회귀 모델을 비교했습니다.

학습 과실은 48개이고 평가 과실은 12개입니다. 같은 평가 과실 12개에 가림 조건을 바꾸어 적용했기 때문에, 가림이 늘어날 때 각 모델의 오차가 어떻게 달라지는지 비교할 수 있습니다.

중요한 입력 조건은 실험실의 전체 사진을 사용했다는 점입니다. 검출한 사과 부분만 잘라 입력한 모델이 아니므로, 이 조건은 이후 기능 통합 때에도 확인해야 합니다.

## 12 무게 추정에서 가림 증강 효과

목표 65초 / 08:30–09:35

화면 안내: 50% 지점의 오차 차이와 오른쪽 예측 변화량 설명

무게 결과입니다. 가로축은 추가 합성 가림률, 세로축은 평균 절대오차인 MAE입니다. 실제 무게와 예측의 차이를 절댓값으로 평균한 값으로, 작을수록 좋습니다.

원본 조건에서 면적 기준은 36.52그램, 원본 ResNet은 14.26그램, 증강 ResNet은 13.41그램이었습니다. 추가 가림 50퍼센트에서는 면적 기준과 원본 ResNet의 오차가 각각 48.66그램, 49.96그램까지 증가했습니다. 반면 증강 모델은 18.48그램으로, 비교한 세 모델 중 가장 작은 오차를 보였습니다.

같은 과실의 원본 대비 50퍼센트 가림 예측 변화량도 원본 학습 43.21그램에서 증강 학습 14.37그램으로 줄었습니다. 이 합성 실험에서는 가림 증강이 무게 예측의 안정성을 높였습니다. 다만 현장 성능은 별도 검증이 필요합니다.

## 13 무게 모델의 촬영 조건과 적용 한계

목표 55초 / 09:35–10:30

화면 안내: 12.92g과 13.41g 비교 후 입력 조건 차이 설명

무게 결과에는 촬영 조건의 한계가 있습니다. 사용한 자료는 카메라마다 촬영한 과실의 무게 범위가 서로 다릅니다. 그래서 카메라별 평균 무게만 답하는 단순한 기준도 오차가 12.92그램이었습니다. 증강 모델의 원본 오차 13.41그램과 비슷한 수준입니다.

따라서 모델이 사과의 물리적인 크기와 무게 관계를 충분히 학습했는지, 아니면 배경이나 촬영 배율 같은 조건을 이용했는지는 추가 검증이 필요합니다.

또 현재 무게 모델은 실험실 전체 화면을 입력으로 학습했습니다. 과수원에서 검출한 사과 부분만 잘라 바로 입력하면 조건이 달라집니다. 새로운 카메라와 촬영 거리에서 평가하고, 배율과 입력 영역을 보정하는 것이 다음 과제입니다.

## 14 자연 가림과 추가 합성 가림

목표 45초 / 10:30–11:15

화면 안내: 자연 가림은 위, 추가 합성 가림은 아래 그림을 가리키기

가림 실험의 의미도 구분해서 설명드리겠습니다. 왼쪽 위의 자연 가림은 데이터가 제공하는 보이는 윤곽과 추정 전체 윤곽을 비교한 것입니다. 실제로 얼마나 가려졌는지를 분석할 때 사용했습니다.

아래의 추가 합성 가림은 원래 보이던 사과 픽셀 중 일부를 녹색 잎 도형으로 더 덮은 것입니다. 따라서 추가 가림 0퍼센트라고 해서 사과에 자연 가림이 전혀 없다는 뜻은 아닙니다.

이번 결과는 정지된 합성 잎 조건에서의 비교입니다. 실제 잎의 움직임이나 조명 변화까지 평가한 것은 아니며, 잎이 움직인 픽셀 수를 실제 풍속이나 풍량으로 해석하지도 않습니다. 움직임에 따른 변화는 후속 실험으로 남겨 두었습니다.

## 15 기능 통합 현황과 연결 순서

목표 45초 / 11:15–12:00

화면 안내: 네 단계의 계획을 위에서 아래로 짚기

기능 통합 현황입니다. 현재 검출·분할과 익음도·무게 분석은 아직 따로 실행하고 있습니다. 보고서에서는 이를 연결하는 순서를 네 단계로 정리했습니다.

먼저 각 기능의 평가 결과를 정리하고, 두 번째로 정답 박스와 마스크를 이용해 임시로 연결합니다. 세 번째로 입력을 YOLO가 예측한 박스와 마스크로 바꾼 뒤, 마지막으로 검출 누락까지 포함한 통합 평가를 진행하는 순서입니다.

이를 위해 이미지 ID와 객체 번호로 같은 사과의 결과를 대응시키고, 박스 좌표와 마스크의 형식을 맞춰야 합니다. 현재는 연결 계획을 정리한 상태이며, 전체 처리 흐름이 구현 완료된 것은 아닙니다.

## 16 통합의 핵심 제약과 다음 조치

목표 65초 / 12:00–13:05

화면 안내: 네 가지 제약과 각각의 다음 조치를 연결해 설명

연결 전에 해결할 핵심 제약은 네 가지입니다. 먼저 무게 모델은 실험실 전체 사진으로 학습했으므로 사과 크롭에 바로 적용하기 전에 촬영 조건과 보정을 검토해야 합니다.

두 번째로 익음도 예측층을 비롯한 일부 모델 파일이 누락되어 있어, 파일을 확보하거나 재학습해야 합니다. 세 번째로 현재 개별 평가는 정답 영역을 사용했으므로 실제 검출의 누락과 영역 오차를 포함한 평가를 따로 진행해야 합니다.

마지막으로 깊이와 실제 지름은 자료를 검토한 단계입니다. 구체적인 보정 방식과 담당을 더 조율해야 합니다. 따라서 단순히 실행 코드를 연결하는 것에 더해 입력 조건, 필요한 모델 파일, 평가 기준과 아직 정하지 않은 범위를 함께 정리하는 것이 통합 준비의 과제입니다.
