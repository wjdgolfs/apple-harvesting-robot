# 사전학습 ResNet18 익음도 분류

정답 박스로 자른 과실 RGB를 입력해 익음과 미숙을 분류했다. ImageNet-1K V1 ResNet18의 최종 풀링 특징 512개를 고정하고 이 데이터에서 이진 분류층을 학습했다. 입력은 종횡비를 보존해 긴 변을 160픽셀로 맞추고 ImageNet 평균색으로 정사각형을 만든 뒤 ImageNet 평균·표준편차로 정규화했다.

> **정정(11월 23일).** 3,023영역으로 다시 평가하면 이 모델이 학습 없는 빨간 픽셀 비율보다 낫다는 근거가 없다([익음도 보강](../../익음도보강/README.md)).

## 분할과 학습

앞선 색 기준 실험의 동일 관측 목록을 썼다. 학습은 895영역(사과 ID 271개, 익음 90건), 검증은 338영역(134개, 익음 22건), 시험은 202영역(115개, 익음 20건)이다. 원본 프레임과 과실 ID는 분할 간 겹치지 않는다. 같은 코드와 시드로 시험용 합성 이미지를 재생성해 파일·영역·가림률별 색 점수와 과실 픽셀 피복 비율을 이전 실험 기록과 대조했다.

- 원본 학습은 895개 원본 입력을 사용했다. 증강 학습은 같은 영역에 원본과 15·30·50% 추가 가림을 적용해 3,580개 입력을 사용했다.
- 각 분류층의 입력 특징을 각 학습 자료의 평균과 표준편차로 표준화했다. 총 클래스 가중치가 각각 0.5인 로지스틱 손실에 L2 패널티(계수 0.1)를 더해 최적화했다.
- 분류 임계값은 각 모델에서 원본 검증 자료의 균형 정확도를 최대화하도록 정했다. 원본 학습 임계값은 로짓 −1.2884, 증강 학습은 −1.9578이었다. 저장한 점수는 로짓이다. 수확 확률로 사용하려면 별도의 보정이 필요하다.

## 동일한 평가 사과에서의 비교

각 칸은 익음 20건 중 찾은 수 / 미숙 182건을 익음으로 잘못 고른 수다. 각 단계는 원래 보이던 면적 중 추가로 덮은 비중이다.

| 추가 가림 | 기존 색 기준 원본 학습 | ResNet18 원본 학습 | ResNet18 가림 증강 학습 |
|---|---:|---:|---:|
| 0% | 17 / 30 | 14 / 28 | 19 / 35 |
| 15% | 8 / 3 | 17 / 38 | 19 / 38 |
| 30% | 0 / 0 | 16 / 47 | 18 / 45 |
| 50% | 0 / 0 | 16 / 59 | 18 / 41 |

가림 증강 학습의 균형 정확도는 차례로 87.9%, 87.1%, 82.6%, 83.7%였다. 50% 추가 가림에서 이 모델이 익음으로 판단한 59건 중 18건(30.5%)에 실제 익음 라벨이 붙었다. 시험 익음 20건은 과실 ID 13개에서 나왔으며 같은 사과의 반복 관측이 포함된다. 정답 위치와 한 종류의 합성 잎에서 평가한 결과다.

## 실행

공통 `imagenet_encoder.py`가 이 폴더의 상위에 있어야 한다. PowerShell에서 이 폴더를 열고 아래 경로 변수를 실제 위치에 맞춘다. `$previous`에는 이전 검수 폴더의 `ripeness`, `occlusion` 두 하위 폴더가 있어야 한다. 특징 캐시는 약 360 MiB가 필요하다.

```powershell
$previous = 'C:\apple-harvest-vision\haerin\2026-11-16'
$data = 'D:\Apple-harvest-data\ripeness'
$weights = 'C:\models\resnet18-f37072fd.pth'
$cachePath = '.\cache'
python prepare_ripeness.py --data $data --baseline-root $previous --cache $cachePath
python encode_ripeness.py --weights $weights --cache $cachePath --device cuda
python fit_ripeness.py --cache $cachePath --out '.\results'
```

`--device cpu`도 사용할 수 있다. [PyTorch 공식 가중치](https://download.pytorch.org/models/resnet18-f37072fd.pth)와 `results/head_clean.pt`, `results/head_aug.pt`가 각각 인코더와 학습한 분류층이다. `results/predictions.csv`에서 202영역 × 4조건의 정답·점수·예측을 볼 수 있다. `results/metrics.json`에는 네 방법의 혼동행렬, 재현율, 정밀도, 임계값과 가중치 해시가 있다.
